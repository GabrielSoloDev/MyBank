## Finalidade

Este diretório contém os documentos e o YAML que estavam na biblioteca documental antes da organização. Os arquivos foram movidos para este local sem transformação de conteúdo e são preservados até a aprovação da documentação consolidada.

## Preservação

Esses documentos são snapshots históricos, não arquivos normativos. Podem conter nomes de arquivos, links, sumários e formatação anteriores à estrutura oficial. A atualização editorial deve ocorrer nos documentos da biblioteca oficial, mantendo estas fontes preservadas.

## Biblioteca oficial

Consulte o [índice oficial](../00-governanca/README.md) para localizar documentos vigentes, identificar sua autoridade e acompanhar seu estado editorial.
